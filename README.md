##  🏫 Anurag EM School Website (CMS Platform)

A production-grade full-stack MERN application built to deliver a scalable, content-driven web platform for educational institutions.
The system includes a custom Content Management System (CMS) enabling administrators to manage website content independently without developer involvement.

# 🚀 Project Overview

This project was designed to solve a key problem:

Schools relying on developers for every content update.

To address this, a custom CMS platform was built, allowing administrators to dynamically manage:

News & announcements
awards 
Image galleries & media

The system ensures real-time updates, improved operational efficiency, and enhanced digital presence.
---
## 🚀 Overview

This project is a **custom Content Management System (CMS)** that enables school administrators to manage website content such as news, staff, students, and media without requiring technical knowledge.

It eliminates dependency on developers for updates and ensures real-time content management.

---

## ✨ Features

### 🔐 Admin Dashboard
- Add, edit, and delete:
  - News & announcements  
  - Staff & management details  
  - Student information  
  - Image gallery  
- Dynamic updates without code changes  

### 🌍 Public Website
- Responsive (mobile-first design)  
- Dynamic content rendering  
- Clean and user-friendly interface

## 🏗️ Architecture
Users (Admin / Visitors)
↓
React Frontend (UI + Admin Panel)
↓
Node.js + Express API
↓
MongoDB Database
↓
Media Storage
